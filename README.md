- построение вспомогательной задачи;
- поиск допустимого базиса;
- решение основной задачи симплекс-методом;
- программная реализация метода;
- проверка результата с помощью Solver.

## Практическая работа №2

**Тема:** глобальная минимизация липшицевой функции методом Пиявского.

В работе реализованы:

- ввод функции одной переменной;
- оценка константы Липшица;
- построение ломаной-миноранты;
- последовательный выбор новых точек;
- критерий остановки по заданной точности;
- визуализация исходной функции и полученной ломаной.

## Практическая работа №3

**Тема:** условная оптимизация методом множителей Лагранжа.

В работе выполнены:

- проверка регулярности ограничения;

- получение системы необходимых условий первого порядка;
- поиск всех допустимых стационарных точек;
- определение глобального минимума и максимума;
- программная проверка решения с использованием SymPy;
- визуализация допустимого множества и экстремальных линий уровня.
